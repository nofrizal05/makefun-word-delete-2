Delete 'Irregardless' — a tiny Python program that writes one funny line to `entry.txt`: the one word it would delete from the dictionary, and why. The word is "irregardless": a typo that showed up so often the dictionary gave up and adopted it, and now it corrects me.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
